## 过程类内容用什么组件

讲解 sam 本身时可以说：有序过程应使用 flow，多角色消息应使用 sequence。这是产品规则说明，不是把规划口令塞进无关项目页。

```flow
识别面板问题 -> 选择 MUST 组件
选择 MUST 组件 -> 写读者正文
写读者正文 -> 渲染自检
```
